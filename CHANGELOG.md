# Changelog

All notable user-visible changes to the HoloPlay TOS application package.

## 1.12.3-1 — 2026-11-12

### Added
- First release. HoloPlay (`spout8301/holoplay:1.12.3`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8116 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/holoplaydocker/`.
